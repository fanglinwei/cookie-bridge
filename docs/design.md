# Cookie Bridge 视觉设计规范

本文件记录已确定的 Logo 设计理念与品牌主题色，作为后续页面设计、图标导出和视觉调整的依据。

## 产品与设计目标

Cookie Bridge 用于选取、收藏、跨站应用 Cookie。视觉应简洁、清晰，突出 Cookie 与站点连接的关系，并适合浏览器工具栏的小尺寸展示。

## Logo 理念：饼干 + 桥拱

![Cookie Bridge Logo](../assets/logo/cookie-bridge-128.png)

- **饼干轮廓**：圆形主体、右上方缺口和三颗颗粒，表达 Cookie。
- **桥拱负形**：主体底部的拱形留白形成桥洞，呼应 Bridge 与跨站传递。
- **圆角方形底板**：统一图标轮廓，使图形在工具栏和扩展管理页中易于识别。
- **两色平面表达**：不使用渐变、阴影、纹理或图标内文字，保留小尺寸下的辨识度。

图形表达 Cookie 的连接与应用，不额外添加云同步、加密或安全认证等产品未提供能力的符号。

## 已确定的品牌主题色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 品牌主色：钴蓝 | `#4164EB` | Logo 底板；后续页面主操作与选中态的品牌色依据 |
| 品牌前景：近白 | `#F8FAFF` | Logo 饼干图形；钴蓝底色上的前景色 |

钴蓝与近白组合传达清爽、明确的工具产品气质。原版深绿 `#176D5D` 与奶油色 `#FFF0D6` 已被替换，不再作为 Logo 配色。

页面采用品牌色时，优先复用现有 CSS 变量与组件样式；悬停、焦点和禁用状态应分别验证可辨识性。错误、警告、成功等状态保留各自语义，不因品牌色统一而混用。文本与背景需要满足可读性要求，状态不能只靠颜色区分。

## 图标使用规范

- 保持 1:1 比例，完整显示图形；不拉伸、不裁切、不旋转。
- 保留 SVG 内置留白与圆角，不再套一层有色底板或装饰边框。
- 以 SVG 为设计源文件；变更后同步重新导出所有 PNG，避免多套图标不一致。
- 浏览器扩展配置使用 PNG；页面品牌区使用 SVG。
- 页面标题旁的 Logo 使用空 `alt`，避免与相邻的 “Cookie Bridge” 重复朗读；单独承载品牌含义时使用 `alt="Cookie Bridge"`。

| 文件 | 使用位置 |
| --- | --- |
| `assets/logo/cookie-bridge.svg` | 矢量源文件、弹窗与管理页品牌区 |
| `assets/logo/cookie-bridge-16.png` | 小尺寸工具栏图标 |
| `assets/logo/cookie-bridge-32.png` | 工具栏高密度显示、页面 favicon |
| `assets/logo/cookie-bridge-48.png` | 扩展图标资源 |
| `assets/logo/cookie-bridge-128.png` | 扩展管理等较大尺寸展示 |

## 当前落地范围

源码已将 Logo 接入 Manifest 的扩展图标及工具栏图标、弹窗与管理页的共用品牌区，以及页面 favicon。

Logo 与页面主操作、选中态采用钴蓝品牌色；具体视觉规范见上文。

## 变更验证

修改 Logo 或引用路径后，执行 `npm run check`，检查生产构建包含 Manifest 引用的 PNG、页面引用的 SVG 和 favicon。重新加载扩展后，检查工具栏、弹窗、管理页以及窄屏布局中的显示，确保 Logo 不变形、不挤压标题。
